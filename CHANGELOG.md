# Changelog

## 0.1.0 — 2026-10-21 (borrador / draft)

**ES**
- Reestructuración completa del repositorio: ahora es específico de Imperva Cloud WAAP y bilingüe (español e inglés).
- Nuevos runbooks: ABP por fases, excepciones sin perder visibilidad y diagnóstico WAF vs. origen.

- Se retiró el contenido sobre SDK móvil hasta contar con validación práctica.
- Se eliminó la promesa de cobertura multiplataforma que no estaba respaldada por el contenido.

**EN**
- Full restructuring: the repository is now Imperva Cloud WAAP–specific and bilingual (Spanish and English).
- New runbooks: phased ABP rollout, exceptions without losing visibility, and WAF-vs-origin diagnosis.
- ABP flag names from the previous version were corrected and terminology was unified.
- Mobile SDK content was removed until it can be validated in practice.
- The multi-platform coverage claim, which the content did not support, was removed.
